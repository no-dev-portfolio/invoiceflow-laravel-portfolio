# 制約・非対象

- localhost・架空データ専用。デモ用アカウントは公開された固定資格情報。稼働サーバーをインターネットへ公開しない。
- 顧客は一覧/追加、請求書は下書き作成/編集/発行/取消、入金は記録のみ。顧客編集/削除、入金取消/返金、メール/PDF配信、見積/会計/銀行連携はない。
- 印刷はブラウザーの印刷機能。適格請求書や実際の会計帳票の制度要件を満たす実装ではない。
- 一般ユーザー登録・パスワード再発行・RBAC/管理者UI・メール認証は未実装。利用者ごとの所有分離はあるが、組織の権限モデルを再現するものではない。
- SQLiteのみ実行確認。DB直書き、サーバー管理者の改ざん、複数ノードは対象外。
- ダッシュボードは自分の請求書をメモリ上で集計。大規模データの性能/大量同時アクセスを保証しない。
- ロック競合はSQLiteの待機とLaravelのリトライを利用する。長時間の外部ロックに対する統一HTTP503や監視・復旧は未実装。
- 操作履歴は取引成功イベントを記録するが、改ざん防止・署名・長期保全はない。
- 依存はcomposer.lockへ固定。DockerベースとGitHub Actionsはタグ指定で、全供給網をdigest/SHA固定していない。
- ソース公開用に.env、鍵、DB、ログ、セッション、vendorを除外。ユーザー環境で依存取得と初期化が必要。
- PHP8.4/Linuxコンテナと内蔵ブラウザーで検証。他PHP版、Windowsネイティブ、全ブラウザー、スクリーンリーダー、印刷出力の全環境、バックアップ/復旧、リモートCIは未確認。
