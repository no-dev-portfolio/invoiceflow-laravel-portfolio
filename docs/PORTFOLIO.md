# 案件応募・作品紹介用テキスト

## 作品名

InvoiceFlow — Laravelによる顧客・請求・入金管理

## 紹介文

PHP/Laravelの業務開発案件を想定し、顧客管理、請求書の下書き/発行、部分入金/完済、残高集計を備えた自主制作ポートフォリオです。Laravelのセッション認証、FormRequest、Eloquent、マイグレーション、DBトランザクション、Bladeを使用しました。

入力の妥当性に加え、発行後の変更禁止、利用者間のデータ分離、同じ入金操作の再送、過入金、古い画面からの更新を業務条件として実装しています。PHPUnitで認証/認可/原子性/冪等性を確認し、独立した2つのPHPプロセスを起動する競合試験も用意しました。

Docker/Composer lock、デモSeeder、設計書、検証記録を同梱し、ソースを取得した方がローカルで動作を再現できる構成です。

## 提示する技術領域

PHP8.4 / Laravel13 / Blade / Eloquent / SQLite / FormRequest / セッション認証 / CSRF / トランザクション / 楽観的排他 / 入金の冪等性 / PHPUnit / Docker / GitHub Actions定義。

## 説明上の範囲

AI支援を利用した自主制作であり、受託納品や本番稼働実績ではありません。実際の請求/送金、会計制度への適合、第三者監査済みという表現は使用しません。Laravel以外のフレームワークや別DBへの対応実績をこの作品だけで主張しません。
