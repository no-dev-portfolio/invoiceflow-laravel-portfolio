# 設計・実装の自己レビュー

この記録はCodexによる制作過程の自己点検であり、Claude Codeや人間の独立反証レビューは未実施。

## 1. データ契約・業務整合性

金額を整数円にし、総額上限/デモ税額の丸めを明示。発行後編集と入金後取消を拒否。所有スコープとマスアサインメント経路を確認。同じ入金UUIDで異なる内容を受け付けない条件を追加した。

## 2. UI・検証エラー・認証

日本語Blade画面、状況の文字ラベル、見出し・フォームラベル、フォーカス表示を実装。初回の試験でページ切替ビュー名の不備を検出し、独自の前/次ビューに修正した。配列等の不正型を送った後のold input再表示が失敗しないようFormValueで整形した。

実ブラウザーでログイン、ダッシュボード/詳細、明細追加、下書き132,000円の保存、既存請求の232,000円入金→完済を確認。390px幅の詳細画面でページ幅が390pxに収まることを確認した。

## 3. 並行処理・配布再現性

SQLiteのIMMEDIATE取引と条件付き残高更新を使用。独立したPHPプロセス2つによる過入金/同一UUIDの試験を追加。APP_KEY/DB/ログ/依存ディレクトリを配布しない構成とし、Dockerで別環境を構築して検証した。

元のLaravelスターターに残ったnpm前提のsetupを、この作品用のビルド不要setupへ置き換えた。デモ初期化はlocal/testing限定で、既存キーとデータを維持する。
